# selenium_sports_results
Using Selenium to build a web scrapping tool to get sports results

Bear in mind this project is still under development

#### Why did I use Selenium instead of BeautifulSoup or other tool?
Because I wanted to automate a simple idea using Selenium.

#### Why didn't I use a framework?
Because I wanted to show how I would organize the code myself.
